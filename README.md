# 🛡️ Discord Bot — Росгвардия ГТА 5 РП

Полнофункциональный Discord-бот для управления фракцией Росгвардия.

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка токена

Скопируйте `.env.example` → `.env` и вставьте токен бота:

```
DISCORD_TOKEN=ваш_токен_здесь
```

> Токен берётся с [Discord Developer Portal](https://discord.com/developers/applications)

### 3. Настройка `config.json`

Откройте `config.json` и заполните **все ID**:

- Включите **Режим разработчика** в Discord (Настройки → Расширенные)
- ПКМ на сервер / канал / роль → **Скопировать ID**

#### Какие каналы создать на сервере:
| Ключ              | Назначение                          |
|-------------------|-------------------------------------|
| `applications`    | Заявки на вступление (с кнопками)  |
| `applications_log`| Лог решений по заявкам             |
| `academy`         | Канал академии АВНГ                |
| `reports`         | Рапорты (с кнопками командования)  |
| `work_reports`    | Отчёты о работе                    |
| `promotions`      | Анонсы повышений                   |
| `bonuses`         | Анонсы премий                      |
| `bot_log`         | Лог всех действий бота             |

#### Какие роли нужны:
| Ключ конфига      | Звание                  |
|-------------------|-------------------------|
| `candidate`       | Кандидат [КАН]          |
| `cadet`           | Курсант АВНГ [КУР]      |
| `failed_cadet`    | Не прошёл академию      |
| `private`         | Рядовой [РД]            |
| `corporal`        | Ефрейтор [ЕФР]          |
| `jr_sergeant`     | Мл. Сержант [МЛ.СРЖ]   |
| `sergeant`        | Сержант [СРЖ]           |
| `sr_sergeant`     | Ст. Сержант [СТ.СРЖ]   |
| `warrant`         | Прапорщик [ПРП]         |
| `sr_warrant`      | Ст. Прапорщик [СТ.ПРП] |
| `lieutenant`      | Лейтенант [ЛНТ]         |
| `sr_lieutenant`   | Ст. Лейтенант [СТ.ЛНТ] |
| `captain`         | Капитан [КПТ]           |
| `major`           | Майор [МЙР]             |
| `lt_colonel`      | Подполковник [ПДП]      |
| `colonel`         | Полковник [ПЛК]         |
| `fired`           | Уволен                  |
| `vacation`        | В отпуске               |
| `instructor`      | Инструктор АВНГ         |
| `commander`       | Командир (несколько)    |

### 4. Права бота на сервере

Бот требует следующие разрешения:
- ✅ Manage Roles
- ✅ Manage Nicknames
- ✅ Send Messages
- ✅ Embed Links
- ✅ Read Message History
- ✅ Use Application Commands

> **Важно**: Роль бота должна быть **выше** всех ролей фракции в иерархии

### 5. Запуск

```bash
python bot.py
```

## 📋 Основные команды

### Для всех
| Команда | Описание |
|---------|----------|
| `/анкета` | Подать заявку на вступление |

## 🔄 Система академии

1. Пользователь подаёт `/анкета` → заявка в канал
2. Командир нажимает **✅ Одобрить** → пользователь становится **Курсантом**
3. Инструктор назначает тесты (`/тест назначить`) и практику (`/практика добавить`)
4. Курсант проходит тесты (`/тест пройти <id>`) — **3 попытки** на каждый
5. Инструктор зачитывает практику (`/практика выполнил <id>`)
6. Инструктор выпускает курсанта (`/академия выпустить @user`)
7. Если за **7 дней** не всё выполнено → автоматический статус **"Не прошёл академию"**
